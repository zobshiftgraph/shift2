# Shift Graph (shift2)

Live site: [https://zobshiftgraph.github.io/shift2/](https://zobshiftgraph.github.io/shift2/)

## Source file

Edit **`shiftgraph.html`** — that is the app source.

**`index.html`** is the GitHub Pages entry point. It is updated automatically:

- On push to `main`, the [Sync index.html](.github/workflows/sync-index.yml) workflow copies `shiftgraph.html` → `index.html`.
- Before committing locally, you can run:

```powershell
.\scripts\sync-index.ps1
```

## Local open

Double-click `shiftgraph.html` or open the Pages URL above after pushing.
